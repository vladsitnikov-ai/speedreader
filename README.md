# SpeedReader

RSVP-читалка PDF для macOS и iOS: слова книги показываются по одному в одном месте экрана
в заданном темпе — глаза не бегают по странице, читаешь с любой удобной скоростью.

**Автор — [Влад Ситников](https://vladsitnikov.com).**
Идея приложения вдохновлена Антоном Булановым и его новой книгой «Природа хитрости».

## Скачать

- **macOS** — [последний релиз](https://github.com/vladsitnikov-ai/speedreader/releases/latest): DMG подписан и нотаризован Apple, открывается без предупреждений.
- **iPhone / iPad** — через TestFlight / App Store (см. страницу релизов).

## Что умеет

- Слова появляются по одному, 100–900 слов/мин, группировка по 1–4 слова; пробел — пауза, ← → — скорость.
- Чистый текст: номера страниц и колонтитулы вырезаются, переносы слов склеиваются.
- Выбор страниц перед чтением — можно пропустить оглавление и техстраницы.
- Библиотека книг, позиция «где остановился», именованные закладки с возвратом к слову.
- Оглавление (из PDF или распознанных заголовков) и поиск по тексту с переходом к месту.
- Цитатник с привязкой к изданию и странице: «цитата» — Автор. Название. Издательство, год, с. N.
- «Открыть это место в PDF» — страница оригинала с подсвеченным предложением.
- Светлая / тёмная / системная тема; подсветка буквы фиксации (ORP) по желанию.

## Сборка

Проект описан в `project.yml` ([xcodegen](https://github.com/yonaskolb/XcodeGen)):

```bash
xcodegen generate
open SpeedReader.xcodeproj
```

Скрипты: `build_dmg.sh` — локальный DMG; `build_dmg_notarized.sh` — DMG с подписью Developer ID и нотаризацией.

## Конфиденциальность

Приложение не собирает никаких данных: книги, закладки и цитаты хранятся только на устройстве.
См. [PRIVACY.md](PRIVACY.md).
